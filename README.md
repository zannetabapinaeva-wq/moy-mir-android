# Мой мир — Android

Яркое развивающее приложение с объёмными карточками, общением, эмоциями, навыками, расписанием и 1 200 заданиями на 60 дней.

В каждой из четырёх игр руками — по 20 уровней от лёгкого к сложному (всего 80). Ежедневная программа включает 20 заданий в день; её можно проходить частями. Пройденные уровни сохраняются, все уровни открыты для повторения.

## Скачать APK

[Скачать последнюю версию moy-mir.apk](https://github.com/zannetabapinaeva-wq/moy-mir-android/releases/latest/download/moy-mir.apk)

Android 8.0 и новее. Скачайте APK на телефон или планшет и откройте файл для установки. При запросе Android разрешите установку из выбранного браузера или файлового менеджера.

Все картинки и задания включены в APK. Вход в ChatGPT не нужен. Для озвучки используется установленный русский голос Android; для работы речи без интернета загрузите офлайн-голос в настройках синтеза речи устройства.

При первом запуске поле имени пустое. В родительских настройках есть кнопка «Начать заново», которая после подтверждения сбрасывает результаты и возвращает программу к первому дню. Имя, настройки, свои карточки и расписание сохраняются.

Прогресс хранится на устройстве. Резервную копию можно сохранить в файл и восстановить через родительские настройки. Микрофон запрашивается только при записи произношения имени. Музыки, рекламы, аналитики и внешних ссылок в детском режиме нет.

## Сборка и подпись

GitHub Actions собирает APK и проверяет код Android Lint. Ключ подписи и его пароль в GitHub не передаются. Установочный APK подписывается отдельно официальным инструментом Android `apksigner`, проверяется и публикуется в Releases вместе с SHA-256.

Для сборки нужны JDK 17, Gradle 8.9 и Android SDK 35:

`gradle :app:assembleRelease :app:lintRelease`

Полученный `app-release-unsigned.apk` нужно подписать собственным ключом перед установкой. Для совместимых обновлений используйте тот же ключ подписи. Проверка установки и озвучки на физическом устройстве выполняется отдельно.
